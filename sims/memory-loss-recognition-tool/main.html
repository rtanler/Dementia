Common Distinguishing Features

Normal Aging

  • Occasional forgetfulness that self-corrects
  • Retracing steps and remembering
  • Recognizing familiar people even if names slip
  • Using lists and reminders as tools
  • Finding the right word eventually

Dementia Concern

  • Asking the same question repeatedly in minutes
  • Forgetting recently written-down information
  • Getting lost in familiar places
  • Telling the same story many times per day
  • Forgetting safety-critical actions (medications)
Recommendation: If you notice these concerning patterns in yourself or a loved one, consult a healthcare provider for evaluation. Early diagnosis allows for better planning, treatment options, and support.
