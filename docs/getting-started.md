# Getting Started

## How to Use This Textbook

### Navigation

Use the left sidebar to navigate between different sections of the textbook:

- **[Chapters](./chapters/index.md)**: Main content organized by topic
- **[MicroSims](./sims/index.md)**: Interactive simulations and visualizations
- **[Learning Graph](./learning-graph/index.md)**: Visual representation of concept dependencies
- **[Glossary](./glossary.md**): Definitions of key terms
- **[FAQ](./faq.md)**: Frequently asked questions

### Features

#### Search
Use the search bar at the top to find specific topics or terms.

### Self Assessment Quizzes

Each chapter has a short quiz you can take at the end of each chapter.
You will see a link to the "Quiz" on the left navigation panel when you open each chapter.

### Annotated References
If you would like to dive deeper into any chapter, look for a file called "References"
in the navigation bar for each chapter.  We have provide not only links but annotated
descriptions of each reference.

#### Interactive Elements
Look for interactive MicroSims embedded throughout the chapters for hands-on learning.

### Getting Help

If you have questions or need support, please refer to the FAQ section or use the contact information provided.
