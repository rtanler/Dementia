# Memory Loss Recognition Tool

This interactive scenario-based quiz walks you through ten realistic situations
involving older adults experiencing memory lapses. For each scenario you decide
whether it represents **normal age-related change** or a **dementia concern**,
then receive immediate feedback explaining the reasoning and key distinguishing
features. At the end you receive a score, a review of common features for both
categories, and a recommendation for next steps.

## Learning Objective

Apply knowledge to distinguish normal age-related memory changes from concerning dementia symptoms (Bloom Level 3 - Apply)

- **Bloom Level:** Apply (L3)
- **Bloom Verb:** Apply, demonstrate, solve
- **Library:** HTML/CSS/JavaScript with scenario data structure

## How to Use

1. Read each scenario carefully.
2. Click either **Normal Aging** or **Dementia Concern**.
3. Review the feedback panel explaining the correct answer and the key features
   that distinguish normal aging from dementia warning signs.
4. Click **Next Scenario** to continue through all ten cases.
5. Review your final score and the summary of distinguishing features.

## Key Distinguishing Features

**Normal aging** typically involves occasional memory lapses that the person
notices, corrects, and compensates for using lists, reminders, and retracing
steps. **Dementia concerns** involve repeated loss of recent information,
inability to retain newly written-down facts, getting lost in highly familiar
places, and safety-critical lapses such as double-dosing medication.
