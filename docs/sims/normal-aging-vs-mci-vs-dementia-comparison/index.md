# Normal Aging vs. MCI vs. Dementia Comparison

An interactive three-column comparison table that lets learners explore how
normal aging, mild cognitive impairment (MCI), and dementia differ across ten
important dimensions&mdash;from memory changes and independence to risk of
progression and medical treatment. A built-in quiz mode tests learners on
realistic scenarios.

## Learning Objective

Differentiate between normal aging, mild cognitive impairment, and dementia
across multiple dimensions (Bloom Level 4 - Analyze).

- **Bloom Level:** Analyze (L4)
- **Bloom Verb:** Differentiate, distinguish, compare, contrast
- **Library:** Custom HTML/CSS/JavaScript

## How to Use

- **Explore mode:** Click any cell in the color-coded table to see an
  expanded explanation. Click a dimension label (the left column) to
  highlight the entire row and see all three conditions side by side.
- **Quiz mode:** Read each scenario and choose which condition best fits
  the description. Answer all five correctly to see a celebration.

Color key:

- **Green:** Normal Aging
- **Yellow:** Mild Cognitive Impairment (MCI)
- **Orange:** Dementia
